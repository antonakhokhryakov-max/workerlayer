# Control plane (trusted)

Persistent Worker, CapabilityManifest, temporary task identity, declared capabilities, policy, approvals, audit, and the Milestone 1 EnvironmentCompiler stub (copy the declared spec).

**Worker → Task → CapabilityManifest → WorkerEnvironment → execution**

Agent intent is never authorization. Every action is allowed, denied, or sent for approval here — including actions requested by our own first-party agent.

**Alpha — not for sensitive production workloads.** This is a foundation, not enterprise zero-trust.
