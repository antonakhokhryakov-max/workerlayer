# Workers (untrusted)

The first-party knowledge worker is dogfood on `AetherPlatform`. It requests tools. It does not authorize and it does not execute.

The North Dock chief of staff is the Instinct-for-X vertical: domain logic and registered `staff.*` tools on the same Worker / Task / CapabilityManifest / WorkerEnvironment path. It registers with `registerWorker` like any other vertical.

The Cedarline Claims Agent is a demo of an embedded vendor worker. It is not a product line.

Neither worker may import the control plane or workstation. Being first-party is not a privilege.

**Alpha — not for sensitive production workloads.**
