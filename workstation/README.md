# Execution (untrusted)

The composed WorkerEnvironment: task files, DIRECT_TOOL adapters, SANDBOX python, and allowlisted fetch.

Executes only after the control plane issues a one-time grant. Compute HOW is a `ComputeProvider`: Docker when the daemon is healthy, else `unshare-mount`, else `process-filesystem`. Sticky per Task. Customers do not choose the backend. When the assignment ends the environment is destroyed; outputs and the audit remain on the host store.

Full browser research is not built. MCP and COMPUTER substrates are slots only.

**Alpha — not for sensitive production workloads.**
