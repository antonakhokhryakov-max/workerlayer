# Milestone 4

The assignment desk now shows **delivery score next to human effort**.

That is the number we optimize: high autonomy, low cleanup.

## What you see

On the desk and on each recent task:

- **Accepted with 0 fixes** — finished work, no human cleanup
- **1 fix then accepted** — one structured correction, then accepted
- **Rejected** — the person stopped the assignment

Harbor & Pine and the market pack are summarized side by side. `pnpm aether effort` prints the same comparison. The eval harness writes the same line into each task's evaluation notes.

## What this is not

Not a chat. Not a new review workflow. Accept / one fix / reject, the quality loop, opened desk files, task identity, real denies, and the audit stay as they were.
