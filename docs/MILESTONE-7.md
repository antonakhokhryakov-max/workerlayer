# Milestone 7

Harbor’s default finish is the **0-fix path**.

The first draft still fails on purpose (no Uncertainty sheet, money stripped from the deck). The autonomous correction pass clears those defects before the assignment waits for review. A typical Harbor sample can be accepted with 0 interventions at delivery score 100.

Past 1-fix accepts stay on the board. History is not rewritten.

## What this is not

Not a new screen. Accept / one fix / reject is unchanged. When the pack is already sendable, the review says accept with 0 fixes is the default. The effort board, desk opens, task identity, real denies, and the audit stay as they were.
